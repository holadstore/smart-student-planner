# Year 5 Knowledge Quest — Public Edition

A static, privacy-first educational web game for UK Year 5 / Key Stage 2 English, Maths and Science.

## Public-ready features

- Professional responsive game dashboard
- English, Maths and Science learning worlds
- Full section/topic learning map based on the supplied source books
- Original public-facing lesson summaries, questions and explanations
- Learn → Explain → Play → Master progression
- XP, coins, stars, streaks, badges, daily quests and world challenges
- Parent / Teacher progress screen
- Optional nickname and avatar only; no account required
- Local-only progress storage
- No chat, public profile, advertising, analytics or third-party tracking in this build
- PWA manifest and offline service worker
- Privacy, Terms, About, Parents & Teachers and 404 pages
- Security headers for Vercel deployment

## Publish

This folder can be deployed as a static site on Vercel, Netlify, Cloudflare Pages, GitHub Pages or another static host. No build step is required.

### Vercel
1. Put the folder in a Git repository.
2. Import the repository into Vercel.
3. Framework preset: Other / Static.
4. Build command: none.
5. Output directory: project root.
6. Deploy.

`vercel.json` contains clean URL and security-header settings.

## Before a large public or commercial launch

- Expand and independently QA the question bank for every topic.
- Run accessibility testing with keyboard, screen reader and mobile users.
- Add a real support/contact route for the organisation operating the site.
- Review the final privacy/terms text for the operator's jurisdiction and any new services added.
- If accounts, analytics, cloud saves, payments or ads are introduced, complete a fresh child-privacy and safeguarding review.
- Conduct a final rights/trademark review. Do not use textbook scans, publisher branding or copied exercise banks without permission.

## Content rights

The supplied English, Maths and Science books were used as source material for topic coverage and instructional planning. The public edition uses original interface text, game mechanics, lesson summaries and practice questions; it does not include scanned pages or publisher artwork.
