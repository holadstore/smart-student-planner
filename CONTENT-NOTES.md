# Content and publishing notes

The supplied English, Maths and Science textbooks are used as the organisational and instructional basis for the game.

For a public product, the safest implementation is to use:

- the broad curriculum/topic structure,
- independently written explanations,
- independently written practice questions,
- original visual design and game mechanics.

Avoid publishing scans, copied illustrations, publisher branding, or substantial copied wording from the books without permission.

This package therefore intentionally uses original interface text, original game mechanics, short original summaries and original practice questions rather than reproducing pages from the textbooks.
